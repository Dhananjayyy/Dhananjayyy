<summary><b>🌿 Know Your Compliance — Environmental Compliance Platform</b></summary>
<br/>

Replaces spreadsheet-based environmental compliance tracking for enterprise clients.

- Designed the **overall system architecture** and picked the stack from scratch
- Led a **3-person team** across React frontend, Spring Boot APIs, PostgreSQL modeling, auth, and AWS deployment
- Built **4 role-specific dashboards** (Environmental Officer, Manager, Admin, Third-party) with RBAC and centralized records
- Real-time updates via **WebSockets**

`React` `Spring Boot` `PostgreSQL` `WebSockets` `AWS`
</details>

<details>
<summary><b>💨 Yuka Yantra — Air Purification Analytics Platform</b></summary>
<br/>

Real-time environmental monitoring platform for air purification tech, used by enterprise clients and regulatory bodies.

- Built a **high-throughput MQTT → Redis → WebSocket** pipeline streaming live sensor data to dashboards
- Bulk writes to **MongoDB**, time-partitioned backups to **S3**
- **Dual-token JWT auth**, RBAC, **Nginx** reverse proxy, Dockerized on **AWS EC2**
- **CPCB-compliant gauges**, inlet/outlet efficiency comparisons, predictive maintenance tracking, high-contrast kiosk dashboards

`React` `Recharts` `MQTT` `Redis` `MongoDB` `Docker` `AWS EC2`
</details>

<details>
<summary><b>🤖 Ona — Multi-Tenant AI Chatbot (RAG + Multi-Agent)</b></summary>
<br/>

Embedded inside a Department Management System to let department heads query project status and records in natural language.

- **FastAPI** backend, **Qdrant**-backed RAG, **CrewAI**-orchestrated multi-agent workflows (Sustainability & HR agents)
- Custom pipelines for **embeddings, intent classification, and reranking**
- **EcoLogits**-based carbon tracking on every inference call
- Shipped alongside interactive sites built with **Framer Motion** and **VantaJS** (scroll-triggered timelines, 3D effects)

`FastAPI` `LangChain` `CrewAI` `Qdrant` `RAG`
</details>
