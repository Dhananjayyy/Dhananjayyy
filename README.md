<details>
<summary><b>Yuka Yantra</b> — air purification analytics platform</summary>
<br/>

Real-time monitoring platform for air purification technology, used by enterprise clients and regulatory bodies.

- High-throughput pipeline: MQTT → Redis → WebSocket, streaming live sensor data to dashboards
- Bulk writes to MongoDB; time-partitioned backups to S3
- Dual-token JWT auth, role-based access, Nginx reverse proxy, Dockerized on AWS EC2
- CPCB-compliant gauges, inlet/outlet efficiency comparisons, predictive maintenance tracking, high-contrast kiosk dashboards

`React` `Recharts` `MQTT` `Redis` `MongoDB` `Docker` `AWS EC2`

</details>
